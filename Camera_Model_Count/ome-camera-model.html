Camera Model Report

Select a batch of photos and this tallies them by Camera Model, read directly from each file's EXIF data — JPEG and HEIC both supported. Everything runs locally in this tab; nothing is uploaded anywhere.

1 — Select photos

On iPad/iPhone this opens the Photos picker — use Select in the top corner to multi-pick or drag across thumbnails. On a Mac or PC you can also drag photos straight into this box.
Picking a photo this way makes iOS download the full original if it's only stored in iCloud, so Camera Model comes through even for photos affected by Optimize Storage.

2 — Narrow by date (optional)

This filters whichever photos you selected above — a browser can't query your Photos library by date on its own, so pick a broad batch first (e.g. everything from 2020) and let this narrow it down. Both dates are inclusive, covering the full day. Filtering uses each photo's EXIF capture date; if a photo has none, it falls back to the file's modified date and is marked accordingly below.
